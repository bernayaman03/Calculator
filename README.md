# Android Calculator

A simple Android calculator application developed using **Kotlin** and **XML layouts** as part of a mobile application development assignment.

## Features

- Performs basic arithmetic operations: addition, subtraction, multiplication, and division.
- Supports decimal number input.
- Displays calculation results using an EditText field.
- Provides a clear button to reset the calculation.
- Handles division by zero by displaying an error message.

## Technologies

- Kotlin
- Android SDK
- XML Layouts
- Android Studio
- Gradle

## Project Information

This project was developed as an academic assignment to practice Android application development, event handling, UI component interaction, and basic arithmetic operations.

The application was previously tested during development. It has not been retested in its current environment.
